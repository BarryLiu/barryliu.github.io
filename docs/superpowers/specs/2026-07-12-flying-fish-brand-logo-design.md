# “想飞的鱼”品牌 Logo 设计说明

## 目标

为“想飞的鱼 / Flying Fish Lab”建立一套与首页浅色天空、海面和赛博光感一致的品牌标志，并替换导航栏与浏览器 favicon 中现有的抽象折纸鱼。新标志必须首先像一条跃出海面的飞鱼，其次才体现“飞翔”与轻量赛博感。

## 核心造型

- 鱼头朝右上方，整体上扬约 20–25°，呈跃出海面的运动姿态。
- 鱼体使用流线型梭形轮廓，头部圆润、尾柄收窄、尾鳍分叉，避免像鸟、鲨鱼或海豚。
- 放大的胸鳍从鱼身两侧、靠近头部后方的位置展开。胸鳍为向后外侧张开的浅扇形，不能从背部竖起，也不能画成叶片、船帆或鸟翼。
- 大尺寸版本在胸鳍内保留 2–3 条轻量鳍条，以强化“鱼鳍”而非“翅膀”的识别。
- 鱼下方使用一条向上拱起的海面弧线和最多两个水滴表达破水，不绘制大面积海浪、边框或复杂背景。

## 视觉语言

- 主轮廓使用深青色，保证浅色与深色背景下都有清晰边界。
- 鱼身使用青色到蓝色的渐变；胸鳍使用蓝紫色半透明渐变；尾鳍可使用少量品红作为品牌强调色。
- 光效限制为柔和的青色外发光，避免高饱和霓虹堆叠和厚重阴影。
- 造型采用圆润的有机曲线，不使用折纸切面、几何拼接或竖直的大型装饰鳍。

## 资源组成

资源统一放在 `public/assets/brand/`：

1. `logo-mark.svg`：独立品牌图形，透明背景，供组件、分享图或后续页面复用。
2. `logo.svg`：横向完整标志，包含图形、“想飞的鱼”和“Flying Fish Lab”。
3. `favicon.svg`：适配浏览器标签的小尺寸版本，保留鱼体、侧胸鳍和简化海面弧线，去掉鳍条、水滴和细小高光等易糊细节。

不新增 PNG 作为主资源。SVG 是最终源文件，确保高分屏和不同尺寸下保持清晰。

## 网站集成

- `CyberLogo.astro` 使用与 `logo-mark.svg` 相同的矢量结构，继续保留现有中文/英文文案切换和首页链接语义。
- 导航栏中的图形保持约 48 × 32 像素显示，不改变当前导航布局和交互。
- `BaseLayout.astro` 继续通过 `/assets/brand/favicon.svg` 引用站点图标，不增加新的运行时逻辑。
- 页脚继续复用 `CyberLogo.astro` 的紧凑模式，因此会自动获得新标志。

## 小尺寸与可访问性

- 16px favicon 轮廓必须仍能识别出朝右的鱼头、展开的侧胸鳍和跃出海面的方向。
- 装饰性内联 SVG 保持 `aria-hidden="true"`，链接本身继续使用中英文首页 `aria-label`。
- SVG 文件包含可读的 `<title>`，完整标志标题为“想飞的鱼 Flying Fish Lab”。
- 不依赖动画表达 Logo 含义，避免在导航和 favicon 中产生干扰。

## 验证标准

- 自动测试确认三份品牌 SVG 存在、可解析，并包含正确的 viewBox；组件继续引用可访问的首页标签。
- `npm run test` 与 `npm run build` 通过。
- 本地检查 `/`、`/about/` 和任意文章页，确认导航、页脚与 favicon 均已替换。
- 分别在浅色和深色主题下检查导航标志；在桌面导航、移动菜单附近和浏览器标签的小尺寸场景下检查辨识度。

## 非目标

- 不修改首页飞鱼主动画、技术栈环绕动画或其他页面布局。
- 不引入新的图片库、字体或动画依赖。
- 不在本次修改中重构导航栏、主题切换或内容集合。
