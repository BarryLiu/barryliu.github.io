# 首页“想飞的鱼”动态水族馆设计

## 目标

重做首页 Hero 右侧水族馆，使“想飞的鱼”成为唯一视觉主角。成品必须具有清晰、连续的“水下加速、冲破海面、展翼飞翔、俯冲回海”动态叙事，不使用静态构图模拟动效，也不再依赖绿色圆形节点、可见轨道、背景网格或大量边框线条。

## 视觉方向

- 采用“赛博晨曦”配色：下半部使用深海蓝、青蓝和蓝紫，上半部使用银白、淡青天空与少量品红云边，移除当前显脏、显重的绿色。
- 水族馆容器保留必要的圆角裁切，但内部不出现面板框、轨道圈、雷达网格或分割线。
- 画面约 42% 为深海、58% 为浅色天空。中间海面使用渐变亮带和两层缓慢起伏的波浪表现，不绘制生硬的水平分割线。
- 天空包含缓慢横移的柔软云层、少量青色扫描光和品红云边；深海包含流动光雾和少量气泡。所有背景元素保持低对比度，避免争抢焦点。
- 场景需要具备垂直镜头跟随效果。飞鱼破水后，不能只让鱼在固定背景上向上平移；天空、海面和深海层必须共同移动，让观看视角产生跟随飞鱼上升的感觉。
- 飞鱼使用可分层运动的 SVG：鱼身、鱼翼、鱼尾和高光可分别动画。造型需要同时表达“鱼”和“展开翅膀飞行”，不能只是现有鱼标识的机械放大。
- 飞鱼造型必须与整体运动方向一致：鱼头位于右侧、鱼尾位于左侧。水下游动、破水上升、天空滑翔和向右下方俯冲阶段都保持鱼头朝向运动方向，不能出现鱼头朝左却向右移动的倒游效果。
- 飞鱼破水并完全展翼后，在实体鱼翼后方显示两至三层低透明度翅膀虚影。虚影使用相同翼型但略微错位、缩放和延迟展开，表现高速振翼与残像；水下阶段不显示，俯冲回海前逐渐消散。
- 技术主题改为五组个人技术栈：`JAVA · SPRING`、`TYPESCRIPT · VUE`、`PYTHON · FASTAPI`、`AGENT · RAG`、`DOCKER · LINUX`。标签在鱼的局部坐标系中沿两层不可见椭圆轨道旋转：外层放置 Java、TypeScript、Python，内层放置 Agent、Docker。文字自身保持正向，不随轨道倒转；经过鱼身后方时降低透明度，经过前景时增强亮度，从而形成空间层次。

## 动画叙事

主循环为“水下加速 → 冲破海面 → 展翼飞翔 → 俯冲回海”，建议每轮约 12 至 14 秒：

1. 飞鱼从左下深海区域游入并逐渐加速，鱼尾快速摆动，鱼翼保持收拢，五个技术栈标签以较低亮度围绕鱼旋转。
2. 接近海面时鱼身明显抬头，水下尾迹拉长，海面亮带轻微聚焦，形成冲刺前的蓄力感。
3. 飞鱼冲破海面，产生短促的放射状水花、扩散波纹和数颗向上飞出后下落的发光水滴。
4. 鱼翼在出水瞬间完全展开，飞鱼沿抛物线穿过浅色云层向右上方滑翔。镜头以略慢于飞鱼的速度平滑向上跟随：海面向画面底部下降，深海区域被逐渐压缩，天空扩展为约 80% 至 90% 的主体画面。技术关键词逐渐点亮，跟随鱼进入天空并继续环绕旋转。
5. 飞鱼在天空中短暂滑翔。此阶段构图以浅色赛博天空和云层为主，海面只在画面最底部保留少量视觉提示，不能继续占据画面中部。实体鱼翼后方的翅膀虚影以轻微时间差展开、漂移和淡出，不能形成厚重的重复轮廓。
6. 飞鱼缩翼俯冲时，镜头比鱼更缓慢地向下回落，海面重新上升；鱼落回海中时产生较弱的波纹和水滴，随后场景恢复初始的深海与天空比例，飞鱼回到左下起点。

除主循环外，云层、扫描光、海浪、背景光雾、气泡、鱼尾、鱼翼、关键词旋转与水滴使用不同周期，避免所有元素同步运动造成机械感。水花仅在出水和入水时间窗出现，不能持续喷溅。

## 实现边界

- 主要改动集中在 `src/components/CyberHero.astro`；只有确有必要时才补充少量主题 token。
- 使用 SVG、CSS keyframes 和少量结构化 HTML 完成，不引入动画库或新增运行时依赖。
- 水平翻转只作用于飞鱼 SVG 图形，不作用于包含技术关键词的环绕系统；关键词必须始终保持正常可读方向。
- 翅膀虚影优先复用 SVG 翼路径，通过独立分组或 `<use>` 元素实现，不复制整条鱼，也不增加位图资源。
- 动画不应触发页面布局变化；优先动画化 `transform`、`opacity` 等属性。
- 镜头效果通过场景内部天空层、海面层和深海层的组合 `transform` 实现，不能移动水族馆容器本身，也不能影响 Hero 或下方内容的页面布局。
- 保持当前 Hero 两栏结构、左侧文案和按钮不变。
- 浅色与深色主题都需要可读。水族馆内部保持自身的“深海到浅色天空”昼夜层次，不随站点主题变成纯白或纯黑。
- 移动端降低水花、水滴、云层和气泡数量，缩短飞行范围；五个技术栈标签仍需全部围绕鱼运动，但可以缩小字号和轨道半径，不能隐藏 Python 或其他标签。

## 无障碍与降级

- 水族馆保留可理解的可访问名称，装饰粒子和背景元素不进入辅助技术阅读顺序。
- 在 `prefers-reduced-motion: reduce` 下停止位移、波浪、云层、水花和关键词旋转动画，静态展示飞鱼已经跃出海面、完全展翼的终态，并把五个技术栈标签均匀分布在鱼周围。
- 动画不依赖鼠标悬停，触屏和键盘用户看到相同叙事。

## 验证标准

- 页面加载后无需交互即可明显看见飞鱼从水下冲出海面、展开鱼翼、在浅色天空滑翔并落回海中的完整过程。
- 飞鱼破水后可以明显观察到镜头随之上升：海面向下移动，深海区域缩小，天空成为约 80% 至 90% 的视觉主体；不能只是鱼在固定背景中上移。
- 画面中不存在绿色圆球、同心圆轨道、雷达网格和 HUD 边框。
- 海面以上清楚呈现浅色天空和云层，同时保留青色扫描光与品红云边形成的轻量赛博朋克氛围。
- 五个技术栈标签始终围绕飞鱼旋转，内容必须准确显示为 `JAVA · SPRING`、`TYPESCRIPT · VUE`、`PYTHON · FASTAPI`、`AGENT · RAG`、`DOCKER · LINUX`。轨道线不可见，文字保持正向；标签不会遮挡鱼眼或形成新的视觉中心。
- 飞鱼在全部可见运动阶段保持鱼头朝右。鱼尾位于左侧并从与鱼身连接的位置摆动，不出现尾部脱节或整条鱼文字一起镜像的问题。
- 飞鱼破水后的天空阶段可以观察到低透明度翅膀虚影；虚影数量为两至三层，仅包含翼型，不复制鱼身或技术关键词，并在俯冲前消失。
- 技术关键词必须处在飞鱼的局部运动容器内，随飞鱼和镜头一起进入天空，不能停留在原海面坐标附近。
- 出水阶段可以观察到短促水花、扩散波纹和下落水滴，其他阶段不会持续出现水花。
- 在首页桌面宽度和移动端宽度下都不溢出 Hero 容器。
- 运行 `npm run test` 与 `npm run build`，并在本地浏览器检查 `/` 的完整动画循环和 reduced-motion 降级。
