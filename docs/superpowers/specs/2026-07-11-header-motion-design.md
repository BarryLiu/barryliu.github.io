# Header 动效优化设计

## 背景与目标

当前站点 Header 功能完整，但视觉反馈偏静态。本次优化参考 Zaro Header 的克制交互方式，并结合“想飞的鱼 / 赛博水族馆”设计系统，为导航增加细腻、低干扰的动态层次。

本次只优化全站 Header，不扩展到首页 Hero、文章卡片或其他页面区域。动效需要兼容现有深色与浅色主题、桌面端与移动端，并尊重用户的减少动态效果设置。

## 视觉方向

采用“克制流光 + 水族呼吸”方向：

- 以 Zaro 式短促、平滑的状态过渡为主体。
- 使用青色低频流光和微弱光晕呼吸强化赛博水族馆主题。
- 避免导航面板持续明显漂移、强烈闪烁或大幅缩放，以免干扰正文阅读。
- 保留现有青色、品红和荧光绿配色，不引入新的视觉体系。

## 动效设计

### 首次进入

Header 首次呈现时执行约 500ms 的轻微下落淡入。位移幅度保持在 8px 以内，使用平滑减速曲线，不使用弹跳效果。

### 滚动状态

页面垂直滚动超过约 40px 后，Header 进入紧凑悬浮状态：

- Header 整体略微上移。
- 导航高度、内边距和圆角轻微收紧。
- 面板背景不透明度、模糊强度和阴影略微增强，使其与滚动内容保持清晰分层。
- 返回页面顶部时平滑恢复初始状态。

滚动监听只切换语义状态类，不在滚动事件中持续计算和写入复杂样式。

### 导航链接

桌面导航增加共享高亮底板。鼠标或键盘焦点进入某个导航项时，高亮底板平滑移动到目标位置；离开导航区域后，高亮淡出。链接文字同时提升亮度，但不单独执行跳动或缩放。

当前页面链接应保持可识别的静态选中状态。交互高亮结束后，底板回到当前页面对应链接；如果没有匹配项则隐藏。

### 面板流光与呼吸

导航面板边框增加低透明度青色流光，低频扫过边缘。Logo 与面板光晕进行非常轻微的周期性明暗变化，模拟水下呼吸感；导航面板本体不持续上下漂浮。

流光和呼吸动画之间错开节奏，避免形成机械同步闪烁。浅色主题降低光晕不透明度，确保边框和文字对比度清晰。

### 操作按钮

搜索、主题、语言、RSS 和 GitHub 控件在悬停或键盘聚焦时：

- 上移约 1px 至 2px。
- 边框和图标颜色增强。
- 出现短促、柔和的局部光晕。

联系入口加入轻微箭头横向位移反馈；不改变原有链接目标和业务行为。

### 移动端

移动端不启用共享滑动高亮、面板呼吸或持续流光。保留以下反馈：

- 菜单按钮悬停、按下和键盘聚焦状态。
- 三条菜单线在展开时平滑转换。
- 菜单面板淡入并轻微上移到位。
- 背景模糊和阴影随展开状态增强。

移动端行为继续基于现有 `details` / `summary` 结构，保证无 JavaScript 时仍可使用。

## 技术实现

主要修改 `src/components/CyberNav.astro`：

- 在现有导航结构内增加共享高亮层和必要的数据属性。
- 使用组件 scoped CSS 实现进入、悬停、流光、呼吸、紧凑状态和移动菜单过渡。
- 使用少量原生脚本监听滚动状态，并计算桌面导航高亮层的位置与宽度。
- 脚本应支持 Astro 页面加载和浏览器尺寸变化，避免重复绑定监听器。

如果深浅主题需要独立参数，只在 `src/styles/tokens.css` 增加 Header 专用颜色、阴影或透明度变量，不修改其他组件的设计变量。

不引入第三方动画库，不改变站点导航数据、搜索逻辑、国际化逻辑、主题切换逻辑或链接地址。

## 可访问性与性能

- 所有悬停反馈同时提供 `:focus-visible` 状态。
- `prefers-reduced-motion: reduce` 下禁用进入位移、共享高亮移动、流光和呼吸动画，仅保留即时或极短的颜色状态变化。
- 动画优先使用 `transform`、`opacity` 和伪元素，避免持续触发布局计算。
- 滚动监听使用被动监听，并通过 `requestAnimationFrame` 合并状态更新。
- 导航功能不得依赖动画脚本；脚本失败时链接、按钮和移动菜单仍可正常使用。

## 验证范围

实现完成后至少验证：

- 运行 `npm run test`。
- 运行 `npm run build`。
- 桌面端检查 `/`、`/ai-notes/`、`/knowledge/`、`/about/`、`/archive/` 和任意文章页。
- 检查页面顶部与滚动后的 Header 状态切换。
- 检查导航链接、搜索、主题切换、语言切换、RSS、GitHub 和联系入口。
- 检查窄屏移动菜单的展开、关闭和键盘操作。
- 检查深色主题、浅色主题以及减少动态效果模式。

## 变更边界与风险

`CyberNav.astro` 当前已有未提交的主题切换及尺寸调整。本次实现必须基于现有工作区增量修改，不覆盖或回退这些变更。

主要风险是共享高亮层在响应式变化、字体切换或语言切换后位置不准确。实现需在窗口尺寸变化以及站点语言变化后重新测量；即使测量失败，也应隐藏高亮层而不是影响导航布局。
