# 计算机中常用的概率知识

## 1. 为什么计算机需要概率

在真实世界里，很多问题都带有不确定性：

- 用户会不会点击广告（无法 100% 确定）
- 模型输出是不是正确（只能给出置信度）
- 网络请求是否超时（有随机波动）
- 推荐系统里用户下一步行为（只能预测概率）

所以概率不是“可选知识”，而是机器学习、搜索、推荐、风控、A/B 测试、系统可靠性分析的基础工具。

---

## 2. 基本概念

### 2.1 随机试验、样本空间、事件

- **随机试验**：结果不确定，但可重复执行（如抛硬币）。
- **样本空间** `Omega`：所有可能结果的集合。
- **事件** `A`：样本空间的子集。

例子：抛一次六面骰子  
`Omega = {1,2,3,4,5,6}`  
事件 `A = {2,4,6}`（掷出偶数）

### 2.2 概率的基本性质

对于任意事件 `A`：

1. `0 <= P(A) <= 1`
2. `P(Omega) = 1`
3. 若 `A` 与 `B` 互斥（`A ∩ B = empty`），则  
   `P(A ∪ B) = P(A) + P(B)`

更一般地：

`P(A ∪ B) = P(A) + P(B) - P(A ∩ B)`

---

## 3. 条件概率与独立性

### 3.1 条件概率

当已知事件 `B` 已经发生时，`A` 发生的概率：

`P(A|B) = P(A ∩ B) / P(B)`，其中 `P(B) > 0`

它表示“在信息更新后，概率如何变化”。

### 3.2 乘法公式

由条件概率可得：

`P(A ∩ B) = P(A|B) * P(B) = P(B|A) * P(A)`

### 3.3 独立性

若 `A` 与 `B` 独立，则：

`P(A ∩ B) = P(A) * P(B)`

等价写法：

`P(A|B) = P(A)`（`B` 的发生不改变 `A` 的概率）

> 注意：互斥通常不等于独立（除非某个事件概率为 0）。

---

## 4. 全概率公式与贝叶斯公式

### 4.1 全概率公式

若事件组 `{B1, B2, ..., Bn}` 两两互斥且并集为 `Omega`，则：

`P(A) = sum(P(A|Bi) * P(Bi))`

### 4.2 贝叶斯公式

`P(Bi|A) = [P(A|Bi) * P(Bi)] / P(A)`

含义：  
由“原因导致结果”的概率 `P(A|Bi)`，反推“看到结果后原因的概率” `P(Bi|A)`。

这在垃圾邮件识别、疾病诊断、故障定位、搜索排序等场景非常常见。

## 5. 随机变量与分布

### 5.1 随机变量

- **离散随机变量**：取值可数（如点击次数）
- **连续随机变量**：取值连续（如响应时间）

### 5.2 概率分布

- 离散：用概率质量函数 PMF `P(X=x)`
- 连续：用概率密度函数 PDF `f(x)`，满足  
  `P(a<=X<=b) = integral_a^b f(x) dx`

### 5.3 常见分布（机器学习常用）

1. **伯努利分布** `Bernoulli(p)`  
   单次二分类结果（成功/失败）

2. **二项分布** `Binomial(n,p)`  
   `n` 次独立伯努利试验的成功次数

3. **泊松分布** `Poisson(lambda)`  
   单位时间内事件发生次数（如请求到达数）

4. **高斯分布（正态分布）** `N(mu, sigma^2)`  
   大量自然现象与误差建模的基础分布

5. **均匀分布** `Uniform(a,b)`  
   区间内各值等可能

## 6. 数学期望与方差

### 6.1 期望（均值）

- 离散：`E[X] = sum(x * P(X=x))`
- 连续：`E[X] = integral(x * f(x) dx)`

期望反映“长期平均水平”。

### 6.2 方差与标准差

- 方差：`Var(X) = E[(X - E[X])^2]`
- 常用形式：`Var(X) = E[X^2] - (E[X])^2`
- 标准差：`Std(X) = sqrt(Var(X))`

方差衡量波动大小。  
机器学习里，方差也常用于理解模型稳定性。

### 6.3 协方差与相关系数

- 协方差：`Cov(X,Y) = E[(X-E[X])(Y-E[Y])]`
- 相关系数：`Corr(X,Y) = Cov(X,Y) / (Std(X)*Std(Y))`

相关系数范围在 `[-1,1]`，用于衡量线性相关程度。

## 7. 大数定律与中心极限定理

### 7.1 大数定律

样本数增大时，样本均值会趋近真实期望。  
这解释了为什么“数据越多，估计越稳”。

### 7.2 中心极限定理

在一定条件下，独立同分布随机变量之和（或均值）在样本量足够大时近似服从正态分布。  
这让正态分布在统计推断中极其重要。

## 8. 机器学习中的概率视角

### 8.1 分类模型输出概率

例如二分类模型输出 `P(y=1|x)`，再根据阈值（如 0.5）做决策。

### 8.2 最大似然估计（MLE）

给定数据，选择参数使“观测到这些数据的概率最大”。  
很多损失函数（如交叉熵）都可由似然推导。

### 8.3 交叉熵与信息量

- 自信息：`I(x) = -log p(x)`
- 熵：`H(X) = -sum(p(x) log p(x))`
- 交叉熵常用于分类任务训练目标

### 8.4 贝叶斯方法

将参数本身当作随机变量：

- 先验 `P(theta)`
- 似然 `P(D|theta)`
- 后验 `P(theta|D) ∝ P(D|theta)P(theta)`

优点是能自然表达不确定性，适合小样本和需要可信度输出的场景。

## 9. A/B 测试中的概率思维（实战）

典型问题：新页面转化率是否真的提升？

你需要关注：

- 样本量是否足够
- 差异是否具有统计显著性
- 置信区间是否跨过 0
- 是否控制了多重比较和提前停止带来的偏差

核心思想：不要只看“提升了多少”，还要看“这个提升有多可信”。

## 10. 学习建议（面向应用开发）

如果你的目标是 AI 应用开发，可按以下顺序掌握：

1. 概率基本规则 + 条件概率
2. 贝叶斯公式 + 常见分布
3. 期望、方差、协方差
4. 大数定律 + 中心极限定理
5. 交叉熵、似然、后验推断（结合模型实践）

配合代码实验（如 NumPy 随机采样、可视化分布）会更容易理解。
